# KM & Company Portfolio

Consulting portfolio for KM & Company focused on paid media, measurement, attribution, ecommerce, creative testing, AI-assisted marketing operations, and growth systems.

## Positioning

**Paid Media · Measurement · Growth Systems**

KM & Company helps brands connect paid acquisition, trustworthy tracking, attribution, creative testing, funnel performance, and revenue so marketing decisions are based on what is actually working.

## Stack

- Next.js 15
- React 19
- TypeScript
- Custom CSS

## Local development

```bash
npm install
npm run dev
```

## Production

Designed for deployment on Vercel from the GitHub repository `kmshabazz/km-company-portfolio`.
